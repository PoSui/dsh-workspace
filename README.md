# dsh-workspace

跨机器同步的 DSH 工作区（私有仓库）。

## 目录
- `个人工作台/` — 档案、决策台账、时间线、购车调研等长期资料
- `绿电绿证资料/` — 绿电绿证业务流程/政策梳理（drawio / png / docx）
- `DSH交接摘要.md` / `交接说明.md` — 新会话接手用的上下文摘要
- `.gitignore` — 排除 `_tools/`、备份 zip、缓存等本地内容

## 使用
两台机器共用本仓库：改动 → 提交 → 推送；另一台 `git pull`。

## 机器对照（别搞混）

| 叫法 | 是谁 | 识别特征 |
|---|---|---|
| **家里机** | 当前这台（DSH 现在跑在这里） | 主机名 `XSH-20230702UWI`；用户目录 `C:\Users\Administrator`；工作区 `D:\dsh-workspace` |
| **公司笔记本** | 上班带的那台，也就是交接文档里的“办公室机 / 办公室电脑” | 用户目录 `C:\Users\破碎`（桌面 `C:\Users\破碎\Desktop`）；10-30 的提交作者是 `破碎 <posui@local>` |

注意：
- 说“这台/本机”= 当前会话所在的机器；指另一台一律说 **公司笔记本**，不要用“办公室机”简称。
- `个人工作台/插件清单.md` 和 `install-dsh-plugins.ps1` 是**公司笔记本写给家里机**的安装材料；文中 `C:\Users\破碎\...` 属于公司笔记本，家里机不要照抄路径。
- 每台机器的 `.dsh/profiles`（插件）和 `_tools/`（令牌等）**不随仓库同步**；`.dsh/skills` 随仓库。
