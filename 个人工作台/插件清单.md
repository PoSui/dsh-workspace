## 三、家里电脑安装步骤

在 DSH 安装目录下用自带 CLI 逐条执行（`--profile desktop` 表示装到桌面版配置里）：

```bash
dsh plugin --profile desktop add dshmarket@1.70.2
dsh plugin --profile desktop add @vectorize-io/hindsight-coding-agents@0.8.2
dsh plugin --profile desktop add billion-context@0.1.209
dsh plugin --profile desktop add dsh-connect-workbuddy@5.12.1
dsh plugin --profile desktop add dsh-context@0.77.0
dsh plugin --profile desktop add dsh-free-search@0.9.17
dsh plugin --profile desktop add dsh-ops@0.4.1
```

嫌麻烦的最短路径：**先只装 `dshmarket`**，打开 DSH 里的插件市场，其余 6 个按名字搜索一键安装，版本会自动取最新。

装完重启 DSH，跑一次确认：

```bash
dsh plugin --profile desktop list
```

应能看到上表 7 个包都在 `dependencies` 里、`dsh.profile.bundles` 里也都列上。
