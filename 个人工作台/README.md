# 个人工作台（可迁移）

**用途**：让任何一个新的 DSH 会话/新电脑，30 秒接手你的事，不用重讲一遍，也不用去啃几百 MB 的会话日志。

**怎么用**
- 新会话开场：让 DSH 先读本目录 4 个文件，再干活。
- 有新结论、新决定：往 `决策台账.md` 加一条；时间点变了：改 `时间线.md`。
- 你不想要随时整个目录删掉，没有任何东西依赖它。

**隐私边界**
- 只记你主动说过的事实，不记密码、账号、身份证号、联系方式。
- 涉及钱和对外发送，先问你。

| 文件 | 装什么 |
|---|---|
| `档案.md` | 不常变的事实：身份、工作、资产、家庭、设备、沟通偏好 |
| `决策台账.md` | 已经定过的结论 + 依据 + 复核条件（避免重复论证） |
| `时间线.md` | 关键日期、待办、触发条件 |
