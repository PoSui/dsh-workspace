# 牛马计时器 · 项目说明（交接用）

> 单文件网页工具：上班时实时显示"今天/本期已经赚了多少钱"，让钱一分一分往上涨。
> 当前版本：**v19** ｜ 测试：`node _tests\harness.js` → **100 条全绿** ｜ 最后更新：2026-11-03

---

## 一、怎么用

双击 `牛马计时器.html`（Edge/Chrome 打开），首次会弹设置窗，填四件事：月薪、每月工作日、上下班时间、午休时间。可选填发薪日（默认 15 号）。

- **点「开始上班」**：按设置里的上班时间算到此刻已经赚了多少，然后继续每秒跳
- **点「下班存档」**：把今天记下来；点错了可以「继续计时（回滚存档）」
- **点日历上本期过去的工作日**：选这天的性质（正常上班 / 80% / 休息 / 带薪假 / 病假 / 加班 1.5~3 倍）
- **攒钱目标**：右上「+ 添加」建目标，点金额可以改目标数
- **打开小窗**：弹 430×380 精简窗，配合 PowerToys 的 `Win+Ctrl+T` 置顶挂屏幕角落

数据全部存在浏览器 localStorage，不联网、不上传。换电脑/换浏览器数据不跟着走——用「导出全部」备份 CSV。

## 三、怎么改、怎么验

```bash
# 1. 改脚本：改 _tests/app.v8.js（真正的源），不要直接改 HTML 里的 <script>
# 2. 把脚本注入 HTML 并同步副本 + ids.json：
#    （见下方"构建三步"，用 python 一行搞定）
# 3. 跑测试
node _tests\harness.js
```

构建三步（python）：

```python
import re, json
h = open('牛马计时器_v19.html', encoding='utf-8').read()
js = open('_tests/app.v8.js', encoding='utf-8').read()
h = re.sub(r'<script>.*?</script>', lambda m: '<script>\n'+js+'\n</script>', h, count=1, flags=re.S)
open('牛马计时器_v19.html','w',encoding='utf-8').write(h)   # 改版本号
open('牛马计时器.html','w',encoding='utf-8').write(h)
open('_tests/app.js','w',encoding='utf-8').write(js)
ids = sorted(set(re.findall(r'id="([\w-]+)"', h)) | set(re.findall(r'getElementById\("([\w-]+)"\)', js)) | {'setupModal','setupMsg'})
open('_tests/ids.json','w',encoding='utf-8').write(json.dumps(ids))
```

**坑（都踩过）**：
- 用正则把脚本注进 HTML 时，替换串里带 `\n` 会被 python 当转义 → 脚本断行、整页 SyntaxError。必须用 `lambda m: '<script>'+js+'</script>'` 这种回调形式。
- 声明 `var LS_XXX` 必须在用到它的函数之前（`var` 提升但不赋值，读出来是 undefined）。
- 事件绑定别写在 `render()` 里——render 每次刷新都跑，容易重复绑定，点一次等于点两次。
- 改了 HTML 不换个文件名，浏览器可能还是旧缓存；让用户 `Ctrl+F5`。

## 四、当前能力（v19 已实现）

1. 主显示：今天已赚（4 位小数）、本期已赚、时薪/每分钟/每秒、距下班倒计时
2. 三条进度：今天进度、本期进度、今天有效工时
3. 设置：月薪、工作日数、上下班、午休、发薪日、休息制度（双休/单休/无休）、加班倍率、刷新频率
4. 账期：发薪日 15 → 账期 10/16~11/15；发薪日 1 → 自然月
5. 日历：每天金额、法定节假日标「休」、调休补班标「班」、今天绿框、未来留白
6. 日期性质菜单（7 项）：正常 / 80% / 休息 / 带薪假 / 病假 60% / 加班 1.5·2·3 倍
7. 攒钱目标：多目标、独立进度条、还差多少、预计达成日、点金额改目标、× 删除、达成打 ✅
8. 存档：下班存档 / 回滚 / 跨天自动收尾
9. 导出：本期 CSV、全部 CSV（带 BOM，Excel 直接开）
10. 小窗模式（配合 PowerToys 置顶）

## 七、给下一位接手的人

- 真正的源是 `_tests/app.v8.js`（名字是历史遗留，实际就是 app.js），HTML 里的 `<script>` 是构建产物
- 改完必须跑 `node _tests\harness.js`，不到 100 条全绿不要交付
- 测试台支持：假时钟 `setClock`、时钟推进 `advance(秒)`、点格子 `clickCell(日期, 类型, 倍率)`、改设置 `setSetting`、造记录 `setRecs`、查文本 `txtOf/moneyOf`
- 每个新功能至少配 2 条断言：一条正常路径、一条边界
