## 3. P1 必修：账期边界

### 3.1 发薪日 28/29/30/31 时账期溢出，最长 59 天、相邻账期重叠

- 位置：`periodRange`，379–386 行。核心三行：
  - 382 `var startThis=new Date(y,m,pd+1);`
  - 383 `var start=(startThis.getTime()<=d.getTime())?startThis:new Date(y,m-1,pd+1);`
  - 384 `var end=new Date(start.getFullYear(),start.getMonth()+1,pd+1);`
- 现象：`pd+1` 会溢出到下个月（尤其 2 月），账期错位且互相重叠。
- 复现（实测日历标题）：
  - 发薪日 = 28，今天 2026-03-01 → 标题 `03-01 → 04-28（04-28 发薪）· 已过 1/59 天 · 工作日 41 天`；应为 `03-01 → 03-28`、28 天。
  - 发薪日 = 31，今天 2026-03-05 → `03-04 → 05-01 · 已过 2/59 天`；应为 `03-01 → 03-31`、31 天。
  - 2027-03-05 同样 59 天。
  - 31 种发薪日跑 2024-01-01→2029-01-01 逐日验证：断裂 136 天，按发薪日 {28:3, 29:8, 30:33, 31:92}；最长账期 {1..27: 31 天, 28:59, 29:60, 30:61, 31:62}。
- 最小改法（先 clamp 再 +1 天，其余调用点不变）：

```js
// 379 行起整体替换
function anchorDay(y,m,pd){                 // 当月锚点：min(发薪日, 当月天数)
  var last=new Date(y,m+1,0).getDate();
  return new Date(y,m,Math.min(pd,last));
}
function boundOf(y,m,pd){                   // 账期边界 = 锚点次日
  var a=anchorDay(y,m,pd); a.setDate(a.getDate()+1); return a;
}
function periodRange(now){
  var d=new Date(now), y=d.getFullYear(), m=d.getMonth(), pd=(S.payDay||15);
  var start=boundOf(y,m,pd);
  if(start.getTime()>d.getTime()) start=boundOf(y,m-1,pd);
  var end=boundOf(start.getFullYear(),start.getMonth(),pd);
  return {start:start,end:end,next:end};
}
```

改完自测：pd=28 在 2026-03-01 → `03-01→03-28`；pd=31 在 2026-03-05 → `03-01→03-31`；pd=31 在 2 月 → 28 天；所有账期 28~31 天且首尾相接。顺带 377/378 行的 `dayInMonth`/`safeDay` 可以从死代码变成有用工具。
