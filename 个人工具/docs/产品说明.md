## 1. 一句话定位

一个双击就能打开的单文件网页，把月薪换算成**此刻正在跳动的钱**，让上班这件事在感官上变成"在赚钱"而不是"在耗时间"。

## 2. 它解决的问题

- 上班时对"我在赚钱"没有实感：工资一个月发一次，日常只有付出感。
- 普通记账/工资条工具回答"这个月赚了多少"，回答不了"现在这一分钟赚了多少"。
- 核心体验只有一个动作：**看一眼，数字在涨**。账期、日历、目标、导出都是为了让这个数字在"下班之后"仍然可信。

明确不做：不核算个税/社保、不做企业考勤、不做多人协作、不做精确工资对账、不对外分享。它是**个人感知工具 + 轻量工时记录**，不是财务系统。

## 3. 使用者与场景

- 使用者：1 人，Windows 本机，浏览器双击打开 HTML；数据只在这台电脑的这个浏览器里，没有账号、没有网络请求。
- 典型一天：到工位点"开始上班"（或按空格）→ 屏幕角落挂着标签页/小窗 → 午休自动停涨 → 18:00 点"下班存档"。
- 月末看账期日历，确认请了几次假、加了几次班、离买车首付还差多少。

## 4. 核心概念（统一口径，其它文档沿用）

| 概念 | 定义 | 代码位置（v19：`牛马计时器.html`） |
|---|---|---|
| 月薪 | 用户手填的基数，可填到手或应发，产品不追问 | 设置 `iSalary` / `S.salary` |
| 每日工时 | `上下班跨度 − 午休跨度`；跨夜自动补 24h；无效值按 0.5h 兜底 | `paidHours()` `:346` |
| 时薪 | `月薪 ÷ 每月工作日 ÷ 每日工时`（工作日默认 21.75） | `hourly()` `:354` |
| 日薪 | `时薪 × 每日工时`（约等于 月薪 ÷ 每月工作日） | `dailyPay()` `:355` |
| 账期（本期） | 按发薪日切：**上月发薪日次日 ~ 本月发薪日**。发薪日 15 → 10/16~11/15；发薪日 1 → 每月 2 号~次月 1 号 | `periodRange()` `:447` |
| 存档 | 点"下班存档"冻结当天：写入 `endMs`/`earnedMs`/`earned` | `stopToday()` `:748` |
| 回滚存档 | "继续计时"删除今天记录，按上班时间重算（含中途离开的时间） | `restartToday()` `:760` |
| 标记 | 给本期过去某天贴类型：正常/休息/带薪假/病假 60%/80% 折工/加班 1.5·2·3 倍 | 菜单 `:277`、`setDayType()` `:934` |
| 目标 | 名称 + 目标额 + 已攒起点 + 起算日；进度 = 起点 + 起算日至今的日值累计；点击金额可改 | `renderGoals()` `:508`、`goalEta()` `:501` |
| 清除基线 | 清空数据时记下当日 `META.clearedAt`，此前的日子不再计入本期/目标 | `clearAt()` `:464` |

两个必须先钉死的口径：

1. **没记录的工作日按"制度日薪"计入本期，休息日计 0；有记录的天一律以记录为准。** 不点开始也能看到本期金额按天增长，这是设计而非 bug。
2. **金额显示保留 2 位小数**（如 `¥450.57`），只有"每秒单价"显示 4 位小数（如 `¥0.0179`）。"4 位小数实时跳"是口头描述，v19 实际不是。

### 5.1 首次打开

没有设置记录时自动弹"先填你自己的数"向导（月薪/工作日/上下班/午休）；"保存并开始"写盘，"先随便看看"也写默认设置。之后不再弹。逻辑见 `openSetup()` `:1006` 与文件末尾 `:1041`。

## 6. 使用流程

正常一天：

1. 首次：双击打开 → 向导填月薪/上下班 → 保存。
2. 到工位：点"开始上班"（或空格）→ 大数字从"上班时间到现在"一次性补到位，然后继续跳。
3. 白天：午休自动停涨；焦点不在输入框时随时可看。
4. 下班：点"下班存档"→ 确认 → 当天冻结，状态变"今天已下班"，出现"继续计时"。
5. 随时：看"本期已赚"、点日历补记请假/加班、看攒钱目标还差多少、点目标金额改数字。
6. 留档：导出本期 CSV（3 列，带合计）或全部 CSV（5 列，带状态）。

异常路径：

- 忘点下班：次日打开自动按设置的"下班时间"给昨天收尾（`finalizeStale()` `:537`），当月合计不会漏。
- 点错存档：点"继续计时（回滚存档）"→ 按上班时间重算；中途离开的时间也算钱，confirm 已写明。
- 半天班/临时外出：v19 无法补录"4 小时"这种粒度，只能实时计时，或整日标记近似（如 80% 折工）。
- 换电脑/清缓存：历史只在本浏览器；先导出 CSV 留底（CSV 不能导回，备份功能未做）。

## 7. 边界与风险（用之前必须知道）

- 单浏览器单配置：换浏览器、无痕模式、清站点数据 = 记录丢失；`localStorage` 写入失败当前不会提示（只有页面错误条）。
- 没有移动端 / 云同步 / 多端：手机看不到。
- 2026 节假日表内置（口径注释写 国办发明电〔2025〕7号）；2027 年及以后按制度工作日计，跨年账期标题会提示"2027 假期未公布"。
- 发薪日 28/29/30/31 的账期边界已 clamp（`harness_ext.js` T1–T7 覆盖），但"31 号发薪"在 2 月会压到 28 号，语义上仍是近似。
- 小窗模式在页面上没有入口（见上表），"配合 PowerToys 置顶"当前无处触发。
- 产品不判断"这笔钱该不该花"；目标只做算术倒推，不构成消费建议。
