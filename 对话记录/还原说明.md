# 会话记录还原说明

`对话记录/会话文件/` 里放的是 DSH 的原始会话记录（`session.v4.jsonl.zstd`），只是快照，不会自动更新。

## 一、先看摘要（推荐）

直接读 `对话记录/对话摘要_20261027.md`，30 秒知道这轮在干什么、还欠什么。**大部分人看到这里就够了。**

## 二、想让 DSH 里出现完整对话

1. 找到 DSH 的会话目录：
   ```
   C:\Users\<你的用户名>\.dsh\sessions\
   ```
   里面按工作区路径分目录，本仓库对应：
   ```
   C:\Users\<你的用户名>\.dsh\sessions\--D-dsh-workspace--\
   ```
2. 在本仓库的 `对话记录/会话文件/` 里，每个 `<会话ID>/session.v4.jsonl.zstd` 复制到上面目录下**同名文件夹**：
   ```
   ...\sessions\--D-dsh-workspace--\session-c2ea3c52-f0e7-454d-a014-4b8b354419f2\session.v4.jsonl.zstd
   ```
3. 完全退出 DSH 再打开，会话列表里就会出现这条记录。

## 三、导出新快照（每次想把最新对话带过去）

在这台电脑的**普通 PowerShell**（不要用 DSH 沙箱）里：

```powershell
# 1) 找到当前会话文件（按修改时间最新）
$s = Get-ChildItem "$env:USERPROFILE\.dsh\sessions\--D-dsh-workspace--" -Directory |
     Sort-Object LastWriteTime -Descending | Select-Object -First 1
$f = Join-Path $s.FullName "session.v4.jsonl.zstd"

# 2) 复制到仓库
$dst = "D:\dsh-workspace\对话记录\会话文件\$($s.Name)"
New-Item -ItemType Directory -Force -Path $dst | Out-Null
Copy-Item $f (Join-Path $dst "session.v4.jsonl.zstd") -Force

# 3) 提交推送
cd D:\dsh-workspace
git add -A
git commit -m "同步会话记录快照"
git push
```

> 注意：会话文件是二进制，二进制文件在 git 里每次改动都会存一份新的，记录多时会慢慢变大。建议只同步**最近一两个会话**，旧的删掉，别让仓库无限膨胀。

## 四、找不到会话目录时

- 确认 DSH 版本：DSH 桌面版默认在 `C:\Users\<用户名>\.dsh\sessions`；
- 如果之前把 `sessions` 做过 junction（本项目历史遗留），它可能指向 `C:\Users\<用户名>\OneDrive\DSH\sessions`，按实际指向找；
- 目录名规则：`--<工作区路径，冒号/反斜杠换成短横线>--`，例如
  `D:\dsh-workspace` → `--D-dsh-workspace--`。
